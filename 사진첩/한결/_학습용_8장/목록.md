# 한결 LoRA — 8장 판 (오빠 경험: 다른 로라도 8장으로 만듦) `[1004]`
> 31쌍(`_학습용`) 중 ★각도·표정·옷/배경이 겹치지 않게★ 고른 8쌍. 캡션은 31쌍판과 같은 길이 양식(머리색 제외).

| 파일 | 역할 |
|---|---|
| hk_01 | 전신 정면 (정자세) |
| hk_05 | 전신 45° 왼쪽 (발 붙음) |
| hk_11 | 전신 정후면 (수영복 뒷면) |
| hk_13 | 책상 방 허리 위 (다른 옷·배경) — 배경 흡수 방지용 |
| hk_27 | 얼굴 정면 클로즈업 (무표정) |
| hk_28 | 얼굴 45° 왼쪽 (은은한 미소) |
| hk_30 | 얼굴 90° 왼쪽 측면 |
| hk_19 | 쇄골 아래 환한 미소 (표정) |

- 8장으로 부족하면 `_학습용`에서 hk_06(3/4 오른쪽 전신)·hk_29(얼굴 45° 오른쪽)·hk_31(측면 오른쪽)·hk_17(무표정)을 더해 12장으로.
