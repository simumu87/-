# v11.0.0-dev 변경 내역

## 새로 생긴 것
- **새 합성기** (`krea2_composer.py`, 메뉴 10번): 사람이 쓴 것처럼 읽히는 한 덩어리 프롬프트. 보통/상세 모드.
  - 인물 → 헤어 → 의상 → 행동·표정 → 피부 → 장소·빛 → 카메라 순서의 서술형. 라벨과 모델용 지시문 없음.
  - 1인은 합친 한 덩어리, 리저널용으로 인물/장면을 나눠 보는 것도 가능(`--parts` 또는 메뉴 선택).
  - 장소 재료는 `krea2_prompt_configs/scene_packs/`(현재 해변: 해질녘/오후/밤/밤(달빛만)).
- **LoRA 구조**: `identity`(얼굴·몸) / `hair`(별도) / `hair_color` / `signature_accessories`(예: 초커).
  헤어를 고르지 않으면 LoRA 헤어 유지, 고르면 LoRA 헤어를 통째로 교체.
- **의상 JSON** (`outfits/lora/*.json`, 목록 `outfits/lists/*.json`): 로라의상 / 공용의상 구분. 검증: `python tools/validate_outfits.py`.
- **표정 사전** `expressions.json`, **헤어 프리셋** `hair_presets.json`.
- **번역풀 파일화**: 옵션 사전 26개를 `krea2_prompt_configs/pools/*.json`으로 분리. JSON만 고치면 반영.
- **한글 설명**: 메뉴의 모든 옵션 옆에 `— 한글 설명`이 표시됨 (번역풀의 `desc_ko`, `option_descriptions.json`).

## 고친 것 (v10.0.3 포함)
창문/문 글자 쪼개짐, 단독 장면의 2인용 표현, 포즈 키 누락으로 생성 실패, 활동 18종 영어 문구 누락(한글 누출), LoRA 미지정 시 `auto` 트리거 출력, 공간 배치 문장 문법 등.

## 작성 원칙
광원과 소재만 적고 빛이 소재에서 어떻게 변하는지는 모델에 맡김 / 색은 인과 없이 직접 / 가시성을 요구하는 문구 금지 / 닫는 문장의 부정 표현은 허용 / 별도 네거티브 입력란은 쓰지 않음.

## 아직 안 한 것
2인(리저널) 합성, 공용의상 풀 연동, 장소 확장(해변 1곳뿐), 남성 LoRA, 입력 번역풀 처리(사전에 없는 말 목록 표시).

## 추가 (옛 모드 통합)
- 메뉴 1~4번(자연어, Smart Random, 조건 지정 랜덤, 빠른 랜덤)이 전부 **새 서술형 프롬프트**로 나온다 (`krea2_prose.py`).
  - 인물 → 헤어 → 의상 → 행동·표정 → 피부 → 장소 → 시간·날씨 → 빛 → 카메라 → 스타일 순의 한 덩어리.
  - 옛 스펙 시트 형식(원단 12속성, `Walls:` 같은 라벨, `scale lock`, `believable` 등)은 쓰지 않는다. 옛 함수는 `compose_prompt_legacy`로 남겨 둠.
  - 1인 약 200~300단어, 2인 약 400단어. 2인은 인물A/인물B/장면을 따로 완결된 글로도 제공(리저널용).
  - 빛 방향은 항상 카메라/피사체 기준으로 풀어 씀(`from front-left` 같은 모호한 표현 제거).
- **설정 메뉴(8번)**: 묘사 분량(보통/상세)과 강화 횟수(자동/없음/1회/2회)의 기본값 저장. 모든 생성 모드에 적용.
- 옵션 반영 검사는 글자 그대로 포함 대신 핵심 값이 문장에 살아 있는지 확인(군더더기 문구 제외).
- 자가진단의 `scale lock` 문장 검사를 `프레이밍 반영 + 모델용 지시문 없음` 검사로 교체.

## 추가 (장면 조합 규칙)
- `krea2_rules.py` + `krea2_prompt_configs/scene_rules.json`(수정 가능): 활동·상호작용·자세를 앉기/걷기/서기 분류로 묶어 서로 맞게 고른다.
  - 상호작용은 활동 분류에 맞는 것만 고르고, 2인 자세는 상호작용에서 정해진다(예: 마주 앉아 대화 → 둘 다 마주 앉기).
  - 밤에는 낮 광원이 나오지 않고(야외는 달빛, 도심은 도시 야간광, 실내는 스탠드/벽등/천장/펜던트), 비·눈·안개에는 햇빛 광원이 나오지 않는다.
  - 의상: 해변에 두꺼운 겉옷, 눈/폭우 야외에 반팔·반바지, 야외 파자마/실내 슬리퍼, 격식 장소 운동복을 걸러낸다(사용자가 고정한 의상은 그대로).
  - 새 광원 `달빛` 추가.
- 점검: `python tests/scene_consistency.py` (자동 장면 1,600건 기준, 이전 합계 약 40% → 0%).

## 추가 ("쓴 건 전부 그리려 한다" 원칙)
- **날씨**: 야외이거나 창가 자리일 때만 쓰고(실내는 "창밖의 비"), 창 없는 자리에서는 날씨 문장과 흐린 하늘빛 광원을 쓰지 않는다.
- **옷은 한 벌이 아니라 한 세트**: 상의가 나오면 하의, 하의가 나오면 상의를 같이 고른다(원피스·파자마 제외). 예전엔 "반바지를 입는다"만 나와 상의가 빠졌다.
- **프레임에 보이는 것만 쓴다**: 전신=상의·하의·신발·액세서리, 허리 위=상의·작은 액세서리, 클로즈업=상의 + 얼굴 쪽 액세서리. 클로즈업/가슴 위는 배경 묘사도 1개로 줄이고 바닥·소품은 생략. 규칙은 `scene_rules.json`의 `visibility`.

- **비치는 소재(오간자, 쉬폰, 레이스, 메시)**에는 항상 불투명한 속층을 같이 적는다(상의 `fitted opaque camisole`, 원피스 `opaque matching slip`, 하의 `opaque lining`). 안 쓰면 모델이 아래를 알아서 정하고 생성마다 달라지기 때문. 규칙은 `scene_rules.json`의 `layers`.

## 속옷/안감 레이어 기본 꺼짐 (2026-10-04)

- 켜면(true) 비치는 소재(오간자·쉬폰·레이스·메시)에 불투명 안감 문장이 붙는다. 테스트도 이 값을 따라간다.

## 화장 선택 (2026-10-22)
- 오빠: 「화장은 아이덴티티에 적은값도 있는데 선택으로 수정할수있게」 + 「에이로 가자」 + 「저 표 자체는 데이터파일로 바꾸는건 됫구」. 의상실 `의상백과_화장표_1006.md`(오빠 36가지 + 여름 정본 1 + 여름이 지어 본 10 = 47줄)를 `krea2_prompt_configs/makeup.json`(스키마 `krea2-makeup/1`)으로 옮겼다. 키 = 화장 이름, 칸 = `num`·`section`·`desc_ko`·`parts_ko`(있는 것만)·`prose_en`(프롬 문구). 원본 표는 그대로 참조용으로 의상실에 남는다.
- `loras.json`에 선택 칸 `makeup` 추가(기본 화장, 없으면 화장 문장 없음). 메뉴 「화장」에서 「LoRA 기본 화장 유지 / 목록 47가지 / 직접 입력」 중 고르면 기본 화장이 통째로 빠지고 고른 것이 들어간다. 명령줄은 `--makeup 이름`.
- 문장은 「She has <prose_en>」(헤어와 같은 규칙: Her/She로 시작하는 완성 문장이면 그대로).
