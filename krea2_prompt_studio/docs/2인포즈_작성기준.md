# 2인 포즈 작성 기준 (krea2-pose-2p/1)

2인 장면에서 두 사람의 몸이 서로 맞게 나오도록 하는 라이브러리. 파일: `krea2_prompt_configs/poses_2p.json`, 코드: `krea2_pose2p.py`. 검수: `python krea2_pose2p.py`

## 0. 전제 (오빠 확정)
- 좌/우는 **사진을 찍는 카메라 기준**(오빠 확정)이다. 리저널 노드가 프레임을 좌/우로 나눈다 → **A는 카메라 왼쪽, B는 카메라 오른쪽**. (보통 A=여자, B=남자) 엔진의 "left/right side of the frame"도 같은 기준이다.
- 적은 건 다 그린다 → 보이는 몸만, 사실 서술로, 한 번만.
- 접촉은 **그 거리에서 닿을 수 있는 것만**. 접촉 없는 포즈(`distance: near`)는 접촉 단어를 쓰지 않는다.

## 1. 칸 구성
| 칸 | 내용 |
|---|---|
| 키 | 본체 `INTERACTIONS` 이름과 같다 (손잡기, 팔짱, ...). 이 이름이면 라이브러리가 엔진 기본 포즈를 대체한다 |
| `desc_ko` | 한글 설명 (필수) |
| `stance` / `distance` | standing·sitting / contact·near |
| `frames_ok` | 접촉이 **보이는 프레이밍**. 여기에 없는 프레이밍이면 라이브러리를 쓰지 않고 엔진 기본으로 돌아간다 |
| `contacts` | 접촉 단어 목록(예: hand). **A와 B 문장에 둘 다** 있어야 한다. 검수 도구가 막는다 |
| `shared_en` | 두 사람 사이 상황 한 문장 (장면 프롬프트에 들어감) |
| `a` / `b` | 관절 인형 순서로 body → arms → legs → head(시선 포함) |

## 2. 문장 규칙
- **좌우(left/right) 금지.** 상대와의 거리로 쓴다: `the arm closest to {po}`, `{p} other arm`.
- 자리표시자: `{p}/{o}` 본인, `{pp}/{po}` 상대(성별 모르면 "the other person"으로 자동 치환되어 두 사람의 their가 안 섞인다).
- `body`는 **분사로 시작**(standing/sitting) — 엔진이 "is"를 앞에 붙인다.
- `legs`는 발이 프레임에 보일 때만 쓰인다(전신, 3/4 전신). 허리 위·무릎 위에서는 자동으로 빠진다.
- `head`에 **시선**을 쓴다. 이 포즈를 쓰면 엔진의 시선 문장은 빠진다 (시선이 두 번 나오면 서로 어긋난다).
- 표정(smile 등)은 쓰지 않는다 — 표정은 엔진이 따로 쓴다.
- 한 부위는 한 번만.

## 3. 새 포즈 추가
1. `poses_2p.json`에 같은 키로 칸 추가 (본체 INTERACTIONS에 없으면 먼저 거기 추가)
2. `python krea2_pose2p.py` → `python tests/regression_bulk.py 60`
3. 접촉 있는 포즈는 `contacts`와 두 문장 단어를 맞췄는지 확인
