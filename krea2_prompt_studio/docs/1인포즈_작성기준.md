# 1인 포즈 작성 기준 (krea2-pose-1p/1)

파일: `krea2_prompt_configs/poses_1p.json` (22종) · 코드: `krea2_pose1p.py` · 검수: `python krea2_pose1p.py`

## 1. 구성
키는 본체 `BASE_POSES` 이름(1인 가능한 22개 전부). 값은 `desc_ko`(한글 설명)와 `parts`.

| part | 내용 | 쓰이는 프레임 |
|---|---|---|
| `body` | 분사로 시작 (standing/sitting/walking ...) — 엔진이 "is"를 앞에 붙인다 | 항상 |
| `arms` | 양팔·손 | 항상 |
| `legs` | 다리·무릎 | 3/4 전신 이하 (depth ≥ 5) |
| `feet` | 발 | 전신 (depth ≥ 6) |
| `head` | 고개의 기울기·방향 | 항상 |
| `gaze` (선택) | 시선. 있으면 이 포즈가 시선을 고정하고 엔진 시선 문장이 빠진다 | 항상 |

## 2. 규칙
- 관절 순서 body → arms → legs → feet → head, 한 부위는 한 번만.
- left/right 금지 — `one hand ... {p} other arm` 식으로 쓴다.
- 표정(smile 등)은 쓰지 않는다 — 표정은 엔진이 따로 쓴다.
- 책·펜·기타처럼 물건이 필요한 포즈는 문장 안에 물건을 적는다 (읽기, 공부, 기타, 피아노, 자전거).
- 시선은 **그 포즈에 자연스러운 목표가 있을 때만** 고정한다(창가에 서기→창밖, 읽기→책). 아니면 엔진 시선을 쓴다.

## 3. 새 포즈 추가
`BASE_POSES`에 이름을 추가한 뒤 같은 키로 칸을 추가하고 `python krea2_pose1p.py` → `python tests/regression_bulk.py 60`.

## 4. 알려진 한계
오빠가 포즈를 직접 고르고 활동은 랜덤이면 "She is baking in a kitchen, riding a bicycle" 같은 조합이 나올 수 있다(엔진이 원래 가진 동작). 활동까지 같이 고르면 자연스럽다.
