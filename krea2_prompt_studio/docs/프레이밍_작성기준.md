# 프레이밍 작성 기준 — 인물이 캔버스에서 얼마나 담기고 얼마나 멀어 보이나

파일: `krea2_prompt_configs/framings.json` (9종) · 코드: `krea2_pose1p.extent_text` · 검수: `python krea2_pose1p.py`

## 1. 글만 보면 어려운 이유
"무릎 위 구도"처럼 이름으로만 말하면 모델이 어디서 자를지, 인물이 얼마나 크게 나올지 매번 다르게 고른다. 모델은 숫자를 못 재지만 **눈에 보이는 기준선**은 따라간다.

## 2. 세 가지를 같이 쓴다
| 요소 | 쓰는 법 | 예 |
|---|---|---|
| ① 자르는 선 | 프레임이 몸의 어디에서 끝나는지 | `the frame ends just above the knees` |
| ② 머리 위 여백 | 머리와 위쪽 가장자리의 거리 | `a small margin above the head` |
| ③ 인물의 비율 | 프레임 높이에서 인물이 차지하는 몫 | `taking up about three quarters of the frame height` |

- 가까운 구도(클로즈업~무릎 위)는 인물이 프레임 높이를 **가득 채운다**고 쓰고 자르는 선으로 구분한다.
- 먼 구도(전신·환경 중심·와이드)는 **비율**로 구분한다: 전신 약 3/4, 환경 중심 약 1/2, 와이드 약 1/4.
- 렌즈(mm)와 시점은 따로 그대로 쓴다. 거리는 렌즈와 비율이 같이 말한다.

## 3. 프레이밍 표 (현재 값)
| 이름 | 자르는 선 | 비율 |
|---|---|---|
| 클로즈업 | 쇄골 | 얼굴이 프레임 높이의 약 2/3 |
| 가슴 위 | 가슴 중간 | 프레임 높이를 채움 |
| 허리 위 | 허리 | 〃 |
| 허벅지 위 | 허벅지 중간 | 〃 |
| 무릎 위 | 무릎 바로 위 | 〃 |
| 3/4 전신 | 무릎 바로 아래 (발 안 보임) | 〃 |
| 전신 | 발 아래 바닥 조금 | 약 3/4 |
| 환경 중심 | — | 약 1/2 |
| 와이드 씬 | — | 약 1/4 |

## 4. 몸 서술과 연결
프레임이 자르는 선 아래의 몸은 **쓰지 않는다**(1인·2인 포즈 라이브러리가 자동으로 뺀다). 팔은 항상, 무릎·정강이는 3/4 전신부터, 발은 전신에서만 쓴다.

## 5. 아직 확인 안 된 것
이 표현이 Krea 2에서 실제로 얼마나 정확히 따라지는지는 **실측 전**이다. 같은 시드로 전신/무릎 위/가슴 위를 뽑아 자르는 선이 맞는지 비교해보고, 어긋나는 프레이밍은 `extent_en`만 고치면 된다(코드 수정 없음).
