# 장소 팩 작성 기준 (krea2-scene-pack/2)

장소를 늘릴 때 이 기준대로 `krea2_prompt_configs/scene_packs/<이름>.json` 한 파일만 추가하면 된다.
`location_ko`가 메뉴 이름이 되고, 코드는 고칠 필요 없다. 검수: `python tools/validate_packs.py`

## 0. 원칙 (오빠 확정)
- **적은 건 다 그린다.** 그러니 보이는 것만, 사실 서술로, 한 번만 적는다.
- **광원은 위치·색·성질만, 소재는 무엇으로 만들어졌나만 적는다.** 빛이 반사되고 색이 변하는 결과는 모델에 맡긴다. (`highlight`, `sheen`, `gloss`, `rim`, `catches the light`, `deepens` 금지)
- 부정문(`no X`) 대신 원하는 것을 구체적으로 적는다.
- 장소 팩에는 **의상 이름을 적지 않는다.** 빛이 닿는 의상 부분은 `{lit}`로 쓴다 (의상 JSON의 `lit_en`, 없으면 "her outfit").
- 장소가 바뀌어도 바뀌지 않는 건 인물 쪽이다. 팩은 장소·빛·순간·카메라만 맡는다.

## 1. 칸 구성
| 칸 | 내용 | 기준 |
|---|---|---|
| `location_ko` | 메뉴 이름 | 본체 장소 이름과 같게 (한글) |
| `outdoor` | 야외 여부 | 실내면 `false`: 하늘·해·달·별·비·눈·안개 단어 금지 |
| `setting_en` | 장소 한 문장 | 종류 + 대표 재질 3개 안팎 |
| `feature_en` | 장소의 주인공 사물 (2개 이상) | 첫 문장은 [0], 상세 모드는 [1]도 씀 |
| `ground_en` | 바닥·표면 재질 (2개 이상) | 소재를 말한다 (oak plank, gray stone) |
| `far_en` | 먼 배경 (2개 이상) | 보통 모드는 1개, 상세 모드는 2개 |
| `times` | 시간대 (아래 2번) | 장소당 최소 1개 |
| `detail_en` | 시간대별 상세 문장 3줄 이상 | 상세 모드에서만 쓰임. 눈에 보이는 사물·표면 |
| `moments` | 장면 속 순간 (아래 3번) | 포즈 + 한 번의 동작/시선 |
| `camera` | 프레이밍별 카메라 문장 (2개 이상) | 키는 본체 `CAMERA_FRAMING` 이름 (전신, 무릎 위, 허리 위...) |
| `position_en` | 인물 위치 | 상세 모드. 장소가 어디에 펼쳐지는지 |
| `ground_contact_en` | 발이 닿은 곳 (선택) | **전신 프레이밍이 있을 때만**, 전신에서만 쓰임 |
| `person_extra_en` | 장소 특유의 인물 서술 (선택) | 예: 해변의 물방울 |
| `more_prefix_en` | 상세 모드의 두 번째 문장 머리말 (선택) | 기본 "Farther along" |
| `style_en` | 스타일 한 줄 | 시간대 안에서 덮어쓸 수 있음 |

## 2. 시간대 (`times.<이름>`)
`time_en` · `time_prep`(at/on/in, 선택. 기본 at) · `sky_en` · `light_en` · `shadow_en` · `desc_ko` (+ 선택: `accent_en`, `far_en`, `ground_en`, `feature_en`, `style_en`, `camera`).
- `light_en`에는 **광원이 어디서 오는지** (camera's left / behind / above 등)가 반드시 들어간다.
- 광원이 왼쪽이면 `shadow_en`은 오른쪽·뒤쪽. 같은 시간대 안에서 방향이 어긋나면 안 된다.
- 실내 `sky_en`은 창 밖이 아니라 방 안의 빛 분위기 (`soft daylight filling the room`).
- 보이지 않는 곳(예: 허리 위 프레임의 바닥)에 그림자를 쓰지 않는다 → 벽이나 책장에 쓴다.
- 시간대가 다르면 달라지는 건 광원·하늘·먼 풍경뿐, 장소 구조는 같다.

## 3. 순간 (`moments.<이름>`)
`pose_en`(동사부터) · `moment_en`({s}로 시작하는 한 번의 동작) · `desc_ko` · `frames`(선택).
- **발·발목이 나오면 `frames: ["전신"]`으로 제한한다.** 안 보이는 건 안 쓴다는 규칙이다 (검수 도구가 막는다).
- 앉는 순간은 `전신`을 `camera`에 두지 않거나 `frames`로 제외한다.
- 포즈는 그 장소에서 물리적으로 되는 것만.

## 4. 자리표시자
`{s}/{S}` she/She · `{p}/{P}` her/Her · `{o}` her(리저널 장면 문장에서는 the woman) · `{color}` 머리색 · `{lit}` 빛이 닿는 의상 부분.

## 5. 새 장소 추가 순서
1. 가장 비슷한 팩(`cafe.json` 등)을 복사해 이름을 바꾼다.
2. `location_ko`·`setting_en`·층(feature/ground/far)을 쓴다.
3. 시간대 1~2개, 순간 1~2개, 카메라 2개를 쓴다. 변형은 나중에 늘린다.
4. `python tools/validate_packs.py` → `python tests/regression_bulk.py 60`

## 6. 현재 팩
해변(시간대 7·순간 3) · 카페 · 아파트 거실 · 침실 · 도시 거리 · 공원 · 서점 (각 시간대 2·순간 2·카메라 2).
의상은 해변은 로라의상(비키니)과 공용의상, 나머지는 공용의상(자동)과 의상 없음을 고른다.

## 7. 한결용 장소 3곳 (1004 추가)
은행나무 길 · 식물원 정원길 · 수국 정원 — 한결 외출복 사진(`사진첩/한결/`)에서 가져온 장소. 의상은 `outfits/lists/hangyeol.json`의 로라의상이 장소별로 걸러 나온다. 의상 JSON의 프레임별 문장 칸(`normal_top_en`·`normal_waist_en`·`normal_noshoe_en`, `detail_prose_en`의 `depth`)은 CHANGELOG 참고.
