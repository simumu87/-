# 번역풀 (옵션 사전)

한글 옵션 이름 → 영어 프롬프트 문구를 담은 파일들입니다. 코드를 고치지 않고 이 파일만 고치면 반영됩니다.

## 형식
```json
{
  "schema": "krea2-pool/1",
  "pool": "TIME_OF_DAY",
  "label_ko": "시간대",
  "items": {
    "해질녘": {"en": "golden hour before sunset", "desc_ko": "해가 지기 직전의 따뜻한 시간"}
  }
}
```
- `en`은 영어 문구입니다. 한글이 들어가면 안 됩니다(자가진단이 잡습니다).
- `desc_ko`는 UI에 보여줄 한글 설명입니다(비워 둬도 동작합니다).
- 항목을 추가/삭제/수정하면 그대로 반영됩니다. 파일이 깨지면 그 풀만 기본값으로 동작하고 경고가 나옵니다.

## 파일 목록 (26개)
테마, 관계, 상호작용, 활동, 시간대, 날씨, 분위기, 사실감, 피부 질감, 프레이밍, 시점, 구도, 심도, 광원,
스타일, 기본 용어집, 색 조화, 색상, 의상 색상, 의상 상태, 신발, 액세서리, 가구, 장식, 생활 소품 등.

## 다시 만들기
기본값으로 되돌리려면 파일을 지우고 `python -c "import krea2_prompt_studio as k; k.export_pool_files()"`를 실행합니다.
(`force=True`를 주면 기존 파일을 덮어씁니다.)

## 아직 파일로 빼지 않은 것 (2단계)
장소(`LOCATIONS`), 포즈(`BASE_POSES`), 의상 종류(`GARMENTS`), 원단(`FABRICS`)처럼 항목 안에 여러 칸이 있는 것,
그리고 영어만 있는 목록(표정, 시선, 헤어 스타일 등)은 구조를 정한 뒤 옮깁니다.

## 번역 모듈과의 관계
- `krea2_translator/data/*.json`: 자유 입력 문장을 용어 단위로 치환하는 사전(기존).
- `krea2_prompt_configs/user_dictionary.json`: 사용자가 추가한 용어(기존).
- 이 폴더: 옵션 메뉴의 한글 이름과 영어 문구(새로 분리).
