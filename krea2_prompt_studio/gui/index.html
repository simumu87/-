가중치 프롬프트

가중치 (비우면 괄호 없이 그대로)

라이팅 트리거 단어 (V67 Lighting) — 고른 단어를 (Lighting:1.1) 뒤에 붙임
모델 페이지는 「전체 문자열을 맨 앞에」 권장이지만, 한 장면에 서로 안 맞는 단어(moonlight + golden hour)를 다 넣으면 장면이 흔들릴 수 있어요. 장면에 맞는 것만 골라 쓰고, 기본은 단어 없이 (Lighting:1.1)만입니다. LoRA 강도 권장 0.65~0.85 (체인은 0.75). 「맨 앞에 붙이기」가 꺼져 있으면 단어도 안 붙어요.
가중치 칸을 바꾸면 「프롬프트 만들기」를 다시 눌러야 반영됩니다. 같은 시드로 두면 문장은 그대로고 가중치만 바뀝니다.
